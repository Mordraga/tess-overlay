# Tess Overlay

A custom stream overlay made for **SeaHellStudios**. It isn't for public use: see [LICENSE](LICENSE).

## For Tess

1. Under **Releases** (on the right), open the newest one and download **Tess Overlay.exe**.
2. Put it anywhere you like (your Desktop is fine) and double-click it.
   If Windows says it "protected your PC", press **More info**, then **Run anyway**. You only see that once.
3. A seahorse appears by your clock and your control panel opens.

That's it. **Updates install by themselves.** Each time the app opens, it checks for a newer version and swaps itself
over. To check right away, right-click the seahorse and pick **Check for updates**. Your settings are kept through
every update.
