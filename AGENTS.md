# Commit messages

- Do not add AI co-author trailers, AI signatures, generated-by notices, agent credit, or promotional links to commit messages or pull request descriptions.
- This applies to Claude, Codex, Copilot, ChatGPT, Gemini, and all other AI tools.
- Describe the actual changes. Preserve legitimate human attribution.
- Do not disable or bypass the repository's commit-message hook.

The local commit-message hook is enabled with `git config core.hooksPath .githooks`.
